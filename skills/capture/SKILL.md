# Capture Skill

Use this when the user gives a thought, link, quote, transcript, reminder, or loose idea that should be saved before it is organized.

## Workflow

1. Preserve the original meaning.
2. Give the note a short plain-language title.
3. Identify the note type: `note`, `idea`, `task`, `person`, or `source`.
4. Add a few practical tags.
5. Save the note in `inbox/` using `templates/note.md` unless a more specific template applies.

## Output

Create or update one markdown file. Do not over-organize during capture.
