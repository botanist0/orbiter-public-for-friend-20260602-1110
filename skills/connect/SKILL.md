# Connect Skill

Use this when a note should be linked to older knowledge or when the user asks what something connects to.

## Workflow

1. Search `knowledge/` and `journal/` for related names, topics, tags, and decisions.
2. Suggest specific links or backlinks.
3. Explain the relationship in one short sentence.
4. Add a `## Related Notes` section only when the relationship is useful.

## Rules

- A weak association is not enough.
- Prefer fewer high-signal links.
- Keep relationship text human-readable.
