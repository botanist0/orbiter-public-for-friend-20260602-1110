# Organize Skill

Use this when the inbox has notes that need decisions.

## Workflow

1. Read the note and decide whether it is a project, area, resource, or archive item.
2. Keep the note title understandable to the user.
3. Add missing context only when it is necessary to make the note useful later.
4. Move the file from `inbox/` to the chosen folder under `knowledge/`.
5. Leave tasks as explicit next actions.

## Rules

- Do not merge unrelated notes.
- Do not invent facts that are not present.
- Prefer a clear imperfect folder over leaving everything in the inbox.
