# Daily Review Skill

Use this when the user wants to wrap up the day, review recent captures, or create a short memory of what changed.

## Workflow

1. Review today's files in `inbox/`, `journal/`, and changed knowledge notes.
2. Summarize new captures and decisions.
3. List follow-ups as plain actions.
4. Create a dated review in `journal/` using `templates/daily-review.md`.

## Output

Keep the review short enough to read in under two minutes.
