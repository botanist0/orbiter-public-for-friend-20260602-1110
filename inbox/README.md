# Inbox

Use this folder for rough captures. During review, move each note into `knowledge/projects`, `knowledge/areas`, `knowledge/resources`, or `knowledge/archive`.

Browser Capture notes are created here. Normal iPhone captures are stored in `usernotes/mobile/`; command captures are stored in `commands/inbox/`; imported email uses `inbox/email/`.

The records in this folder are private by default and should remain ignored by Git except for README files and explicitly reviewed generic examples.
