# Usernotes

Use this folder for ad hoc notes written directly by the user. These are rough notes that should later be processed into inbox notes, project notes, area notes, resources, decisions, or journal entries.

Orbiter indexes and searches this folder. Normal iPhone mobile captures land under `usernotes/mobile/`; browser Capture notes land in `inbox/`; command captures land in `commands/inbox/`.

Usernotes are private personal content and should remain ignored by Git except for this README.
