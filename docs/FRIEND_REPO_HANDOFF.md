# Friend Repo Handoff

Use this when someone else will create or upload a private GitHub repo for Orbiter on your behalf.

## Non-Negotiable Boundary

Only share or upload the sanitized snapshot generated by:

```powershell
npm run public:prepare
```

Safe source folder:

```text
C:\Users\Owner\Orbiter\.public-share\Orbiter-public
```

Do not upload from:

```text
C:\Users\Owner\Orbiter
```

The working repo may contain local-only data, old Git history, ignored files, private inbox records, runtime secrets, travel files, and command history.

## Best Setup

1. Create a new empty GitHub repository.
2. Set visibility to `Private`.
3. Do not initialize it with a README, `.gitignore`, or license.
4. Add the helper as a collaborator with write access only for the upload window.
5. Have the helper push only the sanitized snapshot.
6. Remove or reduce helper access after the review/upload is complete.

If the helper creates the repo under their account, make sure it is private first. They can add you as a collaborator immediately, or transfer ownership later if needed.

## Helper Upload Commands

If using the sanitized folder directly:

```powershell
cd C:\Users\Owner\Orbiter\.public-share\Orbiter-public
git status --short
git commit -m "Initial sanitized Orbiter share"
git branch -M main
git remote add origin <NEW_PRIVATE_REPO_URL>
git push -u origin main
```

If using a zip copy without Git history:

```powershell
cd <UNZIPPED_ORBITER_PUBLIC_FOLDER>
git init
git add .
git commit -m "Initial sanitized Orbiter share"
git branch -M main
git remote add origin <NEW_PRIVATE_REPO_URL>
git push -u origin main
```

If Git reports an unsafe-directory warning for the sanitized folder, trust only that generated folder:

```powershell
git config --global --add safe.directory C:/Users/Owner/Orbiter/.public-share/Orbiter-public
```

## Final Check Before Sending The Link

From the repo folder:

```powershell
rg -n -i "your-real-domain|your-personal-email|your-travel-email|github recovery|orb_[A-Za-z0-9_-]+|BEGIN RSA|BEGIN OPENSSH|BEGIN PRIVATE" .
rg --files | rg "(^|/)(\.orbiter|\.codex|inbox/email/.+\.md|inbox/attachments/.+\.(pdf|png|jpg)|usernotes/.+\.md|journal/.+\.md|commands/inbox/.+\.md|outbox/email/drafts/.+\.md|knowledge/(decisions|projects|areas|resources|archive)/.+\.md|issues-journal/.+\.md|app/search-index\.json)"
```

Expected result: no private account strings, no real secrets, and no private data files. Generic documentation warnings about rotating secrets are acceptable after manual review.
