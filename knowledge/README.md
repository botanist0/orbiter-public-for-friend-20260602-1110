# Knowledge

This folder holds durable markdown notes. Keep notes small enough that a person can scan them and an assistant can retrieve them without pulling in too much context.

## Structure

- `projects/` - active outcomes with deadlines or finish lines.
- `areas/` - ongoing parts of life or work that need maintenance.
- `resources/` - reference notes, source summaries, and reusable ideas.
- `decisions/` - decision records with context, pros, cons, alternatives, and outcome.
- `archive/` - inactive or historical notes.

Knowledge contents are private by default and ignored by Git except for README files. Promote only scrubbed, intentional notes into public documentation under `docs/`.
